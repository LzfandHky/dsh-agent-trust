## `sidebar.md`

```markdown
# 侧边栏

## 这是什么
展示会话树，支持搜索、按状态分组、切换当前会话。

## 如何到达
- 默认可见（应用启动后左列）
- 收起/展开：`Ctrl+B`
- 前置：已登录；至少存在 1 个会话

## 主要动作
| 动作 | 触发方式 | 期望结果 |
|---|---|---|
| 切换会话 | 点击会话标题 | 主区标题变为该会话，URL 变化 |
| 搜索 | 聚焦搜索框并输入 | 列表在输入后 300ms 内过滤 |
| 按状态分组 | 分组下拉选「按状态」 | 列表出现分组标题行 |

## 成功后的可观测状态
- 主区标题元素文本 == 目标会话名
- URL 包含目标会话 id
- 列表项数量 > 0

## 稳定选择器
| 元素 | 标识 | 类型 |
|---|---|---|
| 搜索框 | `role=searchbox[name="搜索会话"]` | 语义 |
| 会话项 | `[data-session-id]` | data 属性 |
| 分组下拉 | `[data-action-id="group-by"]` | data 属性 |

## 常见异常
- 搜索无结果且列表为空 → 检查是否处于"仅显示运行中"筛选 → 切回全部
- 列表卡顿（掉帧）→ 检查是否在渲染线程做了重计算 → 记录长任务耗时
- 出现引导浮层遮挡 → 关闭引导后重试
```

## `cross-cutting-flows.md`

```markdown
# 跨界面流程

## 提交任务 → 队列 → 完成通知
1. 在 `named-agents` 选择智能体，输入任务，提交
2. 底部状态条任务数 +1（可观测）
3. 切到 `queue-and-multitask`，新任务出现在列表首位，状态为「运行中」
4. 任务完成后：列表状态变为「完成」，状态条弹出通知
5. 断言：状态文本变化 + 通知元素出现（轮询，不 sleep）

## 打开 PR → 查看 diff
1. `sidebar` 点击「Pull Requests」
2. 列表出现，点击第一项
3. 右侧预览区渲染 diff，行号可见
4. 断言：`[data-diff-file]` 数量 > 0
```
