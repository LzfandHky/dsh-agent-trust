# Agent trust kit

六个技能，判断一个编程智能体可以信任到什么程度。安装后它们出现在技能目录里，模型可自动加载，也可以 `/skill` 手动调用。

## 包含的技能

| 技能 | 作用 |
|---|---|
| `agent-trust` | 总入口：信任四档、五层强制分层、五阶段落地顺序 |
| `runtime-verify` | 让智能体运行真实应用并自证改动有效（复现 → 修改 → 验证 → 0 报错） |
| `feature-map` | 用户视角的功能地图，把含糊反馈翻译成导航路径 |
| `evidence-first-debug` | 根因前必须先有文件证据与调用链；一次一个假设 |
| `skill-eval` | 评分表 + 伪装目录 + 跨模型判分，把技能当软件测 |
| `agent-ready-architecture` | 结构上让"最短路径即正确路径"，把禁用写法变成 CI 硬失败 |

## 使用

不需要额外命令。触发方式见 `meta.description` 或各技能的 `description`；中文说明见 README.zh.md。

## 边界

技能提供方法与判据，不附带针对具体项目的启动脚本、登录态或选择器；这些需按项目补充。示例以 Web/Electron 为主。

## 覆盖优先级

本包技能 rank 600（随包提供）。`~/.dsh/skills`（400/500）与项目 `.dsh/skills`（100/200）中的同名技能优先，便于按团队习惯本地改写。
